# Translation and talk information search

Searching translated talk information is not currently available. When **Search Target** is set to **Translated Text**, **Search Talk Info** is unchecked and disabled.

You can use either of the following options.

## Search translated transcripts

1. Enter a search string in the translation language
2. Choose that language under **Translation**
3. Set **Search Target** to **Translated Text**
4. Click **SEARCH**

This searches translated transcript text, not translated titles or descriptions. See [Search in translation](../searching-for-words/search-in-translation.md).

## Search English talk information and display translations

1. Enter an English search string
2. Choose a **Translation** language
3. Keep **Search Target** set to **English Transcript**
4. Check **Search Talk Info** and click **SEARCH**

This searches English talk information and displays translated titles and descriptions where available. Selecting a translation language does not make the search query apply to translated talk information. See [Search in talk information](search-in-talk-information.md).
