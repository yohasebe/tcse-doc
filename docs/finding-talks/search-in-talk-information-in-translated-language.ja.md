# 対訳とトーク情報検索

翻訳されたトーク情報の検索は現在利用できません。**Search Target** を **Translated Text** にすると、**Search Talk Info** のチェックは外れ、選択できなくなります。

代わりに、次の2つの方法を利用できます。

## 翻訳された字幕を検索する

1. 対訳言語で検索語句を入力する
2. **Translation** からその言語を選ぶ
3. **Search Target** を **Translated Text** にする
4. **SEARCH** をクリックする

検索対象は翻訳された字幕で、翻訳タイトルや説明ではありません。[翻訳テキストで検索](../searching-for-words/search-in-translation.md)を参照してください。

## 英語のトーク情報を検索して対訳を表示する

1. 英語の検索語句を入力する
2. **Translation** から対訳言語を選ぶ
3. **Search Target** は **English Transcript** のままにする
4. **Search Talk Info** にチェックを入れ、**SEARCH** をクリックする

英語のトーク情報を検索し、翻訳がある場合はタイトルや説明の対訳も表示します。対訳言語を選んでも、翻訳されたトーク情報が検索対象になるわけではありません。[トーク情報で検索](search-in-talk-information.md)を参照してください。
